## 🌟 Highlights

- 🛸 **Interactive 3D Graphics**: Real-time GLB rendering using Google `<model-viewer>` with mouse-tracking camera orbits.
- 🪟 **Progressive Glassmorphism**: 8-stage masked gradient backdrop-blur for authentic frosted glass visuals.
- 🌌 **Particle & Physics Engines**: Deep-space canvas starfields with gravitational cursor attraction.
- 🎬 **Micro-Interactions**: Delightful button animations, kinetic typography, and multi-fold paper unfolding transitions.
- 📱 **100% Responsive & Zero Dependency**: High performance vanilla web technologies built to run lightning-fast on any device.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/pabitralenka07/Web_experiments.git
cd Web_experiments
```

### 2. Run locally
Since all experiments are built with native web technologies, no build steps are required! Launch with any local server:

```bash
# Using Node.js npx serve
npx serve .

# Or using Python 3
python3 -m http.server 8000

# Or using PHP
php -S localhost:8000
```

Visit `http://localhost:8000` (or the provided port) in your browser to experience the gallery! 🎉
