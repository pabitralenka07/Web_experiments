# ✨ Creative Web Animations & Interactive UI Showcase

A curated collection of interactive web animations, 3D product showcases, micro-interactions, canvas experiments, and creative CSS/JavaScript projects.

🔗 **Live Website**: [Deploy on Vercel](https://vercel.com) to view the unified gallery.

## 🚀 Local Setup

Clone the repository and preview with any static local server:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/creative-web-animations.git
cd creative-web-animations

# Preview locally (using any server, e.g. serve or Python)
npx serve .
# or
python3 -m http.server 8000
```

## ☁️ Deploy to Vercel

1. Push this repository to your GitHub account.
2. Go to [vercel.com](https://vercel.com) &rarr; **Add New Project**.
3. Import this repository.
4. Keep the default settings (Framework: *Other*, Root: `./`) and click **Deploy**.
